## Coverage notes

“Documented” means the cited provider documentation was reviewed for the stated scope. It does not mean that an API connection has been built or tested. Amazon SP-API has broader, but still partial, workflow and API coverage. TikTok Shop currently has one focused Partner API operation documented: Get Authorized Category Assets version 202405. Open each guide for its scope, access requirements, and sources.

To request or contribute another marketplace guide, see the repository's [contribution instructions](https://github.com/muhammadrakib2299/Marketplace-integration-playbook/blob/main/CONTRIBUTING.md) and [README](https://github.com/muhammadrakib2299/Marketplace-integration-playbook#add-a-marketplace).

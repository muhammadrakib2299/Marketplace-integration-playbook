# Glossary

- **Marketplace:** A third-party commerce platform where sellers offer products to customers under the platform's rules.
- **Storefront / e-commerce platform:** A seller's own web shop platform; it may connect to a WMS but is not necessarily a marketplace.
- **Marketplace operator:** A technology platform or network used by multiple branded marketplaces. An operator API may serve several storefront brands.
- **Sales channel:** Broad term for a place orders can originate; may include marketplaces, social commerce, and a seller-owned storefront.
- **Aggregator / integrator:** A third party that offers a common API or connectivity layer for multiple channels. Document the aggregator API separately from direct marketplace APIs.
- **Carrier:** A delivery provider. Carrier integrations belong in their own category, not under marketplaces.
- **Access model:** The actual eligibility and authorization path for API access: public, seller-account, approval-required, partner-only, private, or unknown.
- **API surface:** A distinct provider API or partner program with its own authentication, endpoints, versions, or lifecycle. Use this as the unit for folder structure.
- **Evidence label:** A marker indicating whether a claim is official, tested in an authorized environment, or unverified.

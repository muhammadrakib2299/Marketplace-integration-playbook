# Security Policy

This repository is a documentation project and does not provide a production service. If you find a committed credential, personal data, private API material, or another sensitive security issue, do not reproduce it in a public issue or pull request.

Report the issue privately to the repository owner using the contact method available on the owner's GitHub profile. Include the affected file/path and a concise description. Do not send live secrets through public GitHub features. If a credential appears exposed, the owner of that credential should revoke or rotate it immediately; deleting a file or commit does not guarantee that a secret is no longer accessible.

The project does not currently publish security advisories or promise a response-time SLA. Please use only lawful, authorized testing and do not probe marketplace services or accounts as part of a report.

# Code of Conduct

We want this project to be useful and welcoming to people with different backgrounds and levels of experience. Participants are expected to be respectful, constructive, and focused on the technical work.

Examples of unacceptable behavior include harassment, discrimination, personal attacks, deliberate intimidation, sexualized language or imagery, publishing another person's private information, and sustained disruptive conduct. Critique ideas and evidence, not people.

Maintainers may edit or remove content that violates this policy and may temporarily or permanently restrict participation. Report conduct concerns privately to the repository owner through the contact method listed on the owner's GitHub profile. Do not include sensitive details in public issues.

This policy applies in repository issues, pull requests, discussions, and other project spaces. It is adapted for this project and does not replace GitHub's platform policies.
